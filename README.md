# ملعبنا — التطبيق والخادم

الإصدار الحالي: **3.8.61**.

تُدمج رسوم التسجيل مع مبلغ الاشتراك المستحق في سجل واحد، مع الخصم أو الإعفاء، وتبدأ الاشتراكات الدورية من أول الشهر التالي. راجع `UPDATE-NOTES-3.8.61-registration-fee-monthly-start.md`.

هذا المستودع يحتوي على تطبيق سطح المكتب/الويب وواجهة OCR محلية، إضافة إلى خادم
اختياري للمزامنة:

- `malaabna-app/` — تطبيق Electron وملفات الواجهة المشتركة مع PWA.
- `server/` — خادم المزامنة ونسخة الويب المنشورة.
- `.github/workflows/ci.yml` — فحوص البناء والاختبارات وتدقيق الاعتماديات.
- `.github/dependabot.yml` — تحديثات دورية للاعتماديات وإجراءات GitHub.

## البدء السريع

تحتاج Node.js 22.12 أو أحدث. لتشغيل تطبيق سطح المكتب:

```bash
cd malaabna-app
npm ci
npm start
```

لبناء مثبّت Windows:

```bash
npm run dist
```

يمكن أيضاً تشغيل بناء Windows من GitHub Actions يدوياً (`workflow_dispatch`) أو
عند دفع وسم إصدار يبدأ بـ `v`. ينتظر البناء نجاح اختبارات التطبيق والخادم،
ويختبر التثبيت الصامت ويرفع `Malaabna-Setup.exe` كأثر لمدة 14 يوماً. لا يوقّع
المثبّت تلقائياً؛ يلزم إعداد شهادة توقيع قبل التوزيع العام.

للتشغيل والاختبار المحليين لخادم الويب، راجع [دليل الخادم](server/README.md).
ولشرح إعداد مساهمة جديدة والاختبارات المطلوبة، راجع [CONTRIBUTING.md](CONTRIBUTING.md).
تفاصيل بناء تطبيق سطح المكتب والأمان والبيانات موجودة في
[دليل التطبيق](malaabna-app/README.md).

## الأمان والاختبارات

ملفات OCR محلية ولا تُطلب إلا عند تشغيل القراءة المحلية. تُخزَّن ملفات OCR
المستخدمة في PWA بعد طلبها الأول، بدلاً من إضافتها إلى تنزيل التثبيت الأولي.
تعرض الصفحات المخزنة فوراً عند ضعف الاتصال، مع مهلة شبكية للانتقال وبديل مخزن؛
ولا تُخزَّن طلبات API أو التنزيلات أو الروابط ذات معاملات الاستعلام. تفاصيل
التغيير في [ملاحظات الإصدار 3.8.25](RELEASE-NOTES-3.8.25.md)، ودمج التصميم
في [ملاحظات الإصدار 3.8.26](RELEASE-NOTES-3.8.26.md)، وتبديل الثيم في
[ملاحظات الإصدار 3.8.27](RELEASE-NOTES-3.8.27.md).
يشغّل GitHub Actions فحوص المصدر واختبارات التطبيق والخادم، بينما ينشئ
Dependabot طلبات تحديث أسبوعية للاعتماديات وإجراءات CI.

للإبلاغ عن ثغرة، اتبع التعليمات في [SECURITY.md](SECURITY.md).
